# 电力市场政策动态

公开地址：https://ericzhang-ouc.github.io/power-market-policy-updates/

纯前台政策动态网站，无账号、管理员入口、政策库和审核流程。国家、山东分别按发布时间倒序展示卡片，支持搜索及年份筛选，目标范围为2022年1月1日至今。

## 浏览与采集

直接打开 index.html 可本地预览；线上版本由 GitHub Pages 发布。数据从 data/policies.js 读取，兼容 file:// 本地预览。

- 手动增量更新：node scripts/collect.mjs
- 回溯历史：node scripts/collect.mjs --backfill
- 每小时执行：node scripts/sync-hourly.mjs
- 验证：node --test tests/*.test.mjs

采集属于独立的数据维护脚本，不是用户登录或审核后台。GitHub Actions 在每小时第17分钟自动采集、测试、打包并发布；电脑无需保持开机。生成的数据同时提交回仓库，以保留历史记录。

## 来源与范围

scripts/sources.mjs 保存来源及具体栏目配置，包括国家发改委通知、规范性文件、委令、公告、解读、意见征求及反馈；国家能源局最新文件、通知、公告、解读、公示调查；山东能源监管办通知和监管动态；山东能源局公告、调查征集及待解析公开目录；山东发改委待恢复入口。

历史模式扫描官方分页或 JSON 列表，目标起点2022年，最多80页/栏目；每个来源处理后保存进度。增量模式每次最多3页/栏目。采集条目按标题相关性过滤，不代表全站完整收录。已有历史记录保留，新读取失败时不清空旧数据。data/coverage.json 记录本次实际扫描入口、页数、停止原因、选中条目及失败。

山东能源局 HTTPS 当前存在证书域名不匹配，未关闭证书验证；使用可读的官方 HTTP 目录。部分正文返回验证页时，仅保存目录明确给出的标题、日期及原文链接，标为“仅取得官方目录信息”，不生成摘要或虚构附件。山东发改委入口读取失败保留异常状态。未解析的目录不能视为零新增。

网页显示的日期为发布列表日期；元数据日期另存为 documentDate。附件暂记录链接，未下载或验证其全文及效力。正文哈希改变会保存旧记录；哈希包含页面模板，模板变化也可能产生快照。

## 去重及气象数据

- 运行 node scripts/clean-policies.mjs 可重建清理后的卡片；采集器也会自动清理。data/policies.json 的 records 保留原始来源，rows 是展示结果，cleanup 保存合并和排除原因。
- 同地区、同内容类型、同修订标记，发布时间相差不超过14天，且规范标题相同或正式文件文号相同才合并。解读、草案、意见反馈分别保留；不同版本不合并。卡片展开可查看其他官方出处。该规则偏保守，可能仍有少量重复。
- 去除外债、煤炭合同、地方监管新闻误入国家栏目及关联较弱的工程安全/课题公告。原始记录保留，不做不可恢复删除。
- 气象采集：node scripts/collect-weather.mjs。统一更新：node scripts/update-all.mjs。小时脚本已改为调用统一更新，但尚未启用常驻调度。
- 国家及山东政策历史起点仍为2022-01-01；气象、外省、行业观察等后续栏目历史起点为2026-01-01。
- 气象按全国、山东分区展示天气预报与气候预测。默认只显示适用日期未结束的预测；山东每日气象保留官方原文入口。
- 山东短期预报采用中国天气网山东站直接链接的山东省气象台产品。每日气象按用户要求保留官方原文入口，供直接查看内嵌PDF，不要求解析正文。山东预警列表及省级气候预测按用户要求移除，不再展示空栏目或保留未接通入口。
- 全国接入中央气象台天气公报、中期预报及预警滚动产品；国家气候中心气候预测公报。仅记录标题、来源、发布日期及明确的适用日期，不截取预警结论做二次改写。气象采集文件为 data/weather.json、data/weather.js。
- 滚动产品的历史记录仅为标题/发布时间等元数据，链接始终指向官网最新一期；没有存储其历史PDF或全文。月度和延伸期预测按文中具体年份、月份、日序区分有效期，月底跨年情况有回归测试。

年份下拉框使用原生可访问选择菜单及自定义箭头位置：文字左侧12px，箭头右侧12px，控制高度38px；保留原生下拉菜单及键盘操作。山东气象只保留已接通短期预报及用户指定的每日气象原文入口。

UI参考 emseek.com/all 的暖白底色、浅色侧栏、灰色胶囊切换、日期分组和细边框紧凑卡片，使用独立 styles.css 实现；保留本站名称及全部原有浏览功能，不引入评分、收藏或登录。

## 其他省区（2026年起）

南方等区域与各省区统一为一条时间线，不设置地区、年份或搜索筛选。沿用日期分组、卡片省区标注、近三天强调及其他官方出处展开。

- 发现监管机构栏目：node scripts/discover-regions.mjs。依据国家能源局正式派出机构名录，排除单独展示的山东监管办；结果为 data/regional-sources.json。
- 首轮回溯：node scripts/collect-regions.mjs --backfill。日常更新不带该参数，默认最多3页/栏目；回溯最多15页/栏目。
- 复查单个来源：node scripts/collect-regions.mjs --backfill --source=nmg-nyj-notices。
- 重建展示去重：node scripts/clean-regions.mjs。
- 统一更新及小时脚本已包含其他省区，并由 GitHub Actions 持续调度。

首批配置了六个区域监管局、除山东外十一个省级监管办的公开栏目，并补充内蒙古能源局、广东发改委及能源局、山西能源局，合计83个栏目入口。名录范围不等于全国每省每部门均接通。部分栏目动态结构尚未解析或无法读取；data/regions.json 的 sources 保存每个入口的最新状态，data/regional-coverage.json 保存本次或最近可用的覆盖记录。

发布时间须为2026年及以后；文件标题中提到2026年而实际发布于2025年的不纳入。原始 records 与清理展示 rows 分开；国家文件转载、普通行政许可、煤矿油气等无关政务内容不进入展示。省份仅在标题明确指向单一省份时标注，否则保留发布机构所属的区域标签，不把区域管辖范围当成具体政策适用范围。附件记录原文链接，不推断法律效力。

有些省级站点只接入当前列表页，不能保证历史全量。对已核实而当前列表未展示的2026年蒙西、蒙东规则公告，保留一个明确标记的历史种子条目，并仍需读取官方详情验证。

## 精简规则与响应式布局

其他省区进一步聚焦正式规则、细则、办法等文件的发布、修订、征求意见及相关解读。书名号内包含文件类型词的标题优先；不带书名号但明确为正式文件/通知的仍保留。即使提到《规则》，会议、调研、培训和宣贯等工作动态也排除。原始 records 保留，采集后清理与离线重建都使用同一筛选函数。

桌面主内容宽度为视口减侧栏宽度，取消1320px上限，保留单列时间顺序。760px及以下侧栏变顶部三列两行导航，正文满宽单列；360px及以下搜索与年份框各占一行。长标题和来源链接允许换行，卡片底部信息可折行。这些是CSS断点适配，尚未完成手机实机视觉验证。

## 行业观察

运行 node scripts/collect-media.mjs 更新行业资讯；统一更新和小时脚本已包含该步骤。目前仅接入北极星电力市场频道的公开网站目录，收录2026年起的相关文章，保留标题、日期和阅读链接。

已取消“其他”栏目，移除公众号关注名单、独立阅读版与零散署名转载补录，不再采集公众号文章。删除来源也会从历史展示数据中清除，采集失败时不会恢复已移除来源。当前北极星目录共收录84篇；新网站需先验证持续可读的文章列表，再加入配置。

静态发布包：运行 node scripts/build-static.mjs 生成 dist/。GitHub Pages 公开发布及每小时自动调度均已启用，见 DEPLOYMENT.md。

山东栏目也已按其他省区的文件筛选逻辑精简，首轮从97条减至28条，国家栏目仍为151条。政策发布、修订、征求意见、编制说明及解读继续保留，排除会议、现场检查、调研及工作推进报道，即使工作报道引用《规则》也不保留。`node scripts/clean-policies.mjs` 可离线重建，正常采集同样应用筛选；原始 records 及排除原因仍保留。
